# Labs OOP Frontend

React веб-интерфейс для управления функциями.

## Технологии

- React 18 с TypeScript
- Vite
- React Router
- Axios
- Recharts (графики)
- Tailwind CSS (стилизация)
- React Hook Form

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:3000

## Сборка

```bash
npm run build
```

## Функционал

- Регистрация и авторизация пользователей
- Создание функций (математические выражения и табулированные функции)
- Редактирование функций
- Управление точками функций
- Визуализация графиков функций
- Поиск и фильтрация функций
- Темная тема
- Адаптивный дизайн
